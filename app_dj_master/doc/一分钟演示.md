# 一分钟音乐预排演示

在音乐预排页点击 **加载一分钟演示**，再点击 **试听混音**。演出总长 **58 秒**。

两首音乐是本机生成的固定演示素材：Night Drive 和 After Hours，每首 58 秒，均为 120 BPM；两首都从演出时间 00:00 开始。重复载入会得到相同的音乐与编排。

| 演出时间 | 演示内容 |
| --- | --- |
| 00:00–00:05 | Night Drive 和 After Hours 同时开始播放，留出 5 秒开场准备；第二首先保持较低推子电平 |
| 00:05–00:07 | 第一首滤波渐入，并在本段结束前恢复 |
| 00:07–00:12 | 预留 5 秒操作转移时间，音乐继续 |
| 00:12–00:14 | 低频收拢，并在本段结束前恢复 |
| 00:14–00:19 | 预留 5 秒操作转移时间 |
| 00:19–00:21 | 倒放 1 秒，再正放回到倒放前的音源位置；两段合计占用 2 秒，演出增加 2 秒 |
| 00:21–00:26 | 预留 5 秒操作转移时间 |
| 00:22 | 段落标记，对应第一首音源的 20 秒 |
| 00:26–00:34 | 两首同时播放，After Hours 以 8 秒等功率交叉淡变进入；时间轴交叉推子与声音同步 |
| 00:34–00:42 | 预留 8 秒操作转移时间 |
| 00:42–00:45 | 第二首音量推子变化，并在本段结束前恢复 |
| 00:45–00:58 | 留出 13 秒收尾，音乐继续播放至结束 |
| 00:56 | 完成标记 |
| 00:58 | 混音播放结束 |

五个操作依次执行，前一个操作结束到下一个开始至少间隔 **5 秒**。转场期间不再叠加第二首滤波；标记仅用于说明段落，不占用机器人操作时间。搓碟的间隔计算包括倒放后的 1 秒正放回放。

两首音乐在时间轴分行显示，且两条音乐轨道都从 00:00 起：Night Drive 为 00:00–00:58（含搓碟增加的 2 秒），After Hours 为 00:00–00:58。00:26–00:34 的高亮区表示两首同时播放、完成等功率交叉混音。拖动任一音乐片段可改变其演出入场点；该曲目上的事件会随片段一起移动，便于为机器人动作留出间隔。

这里的 5 秒是预排时的准备与回位余量假设，尚未通过真机测量。实际执行前，应实测机器人在相应控件之间的准备、操作和回位时间，再调整节点；若实测来不及，应减少操作数量，保留一分钟展示内的转移余量。

可直接拖动事件调整落点、拉伸持续效果，或在右侧属性中编辑参数。固定按键以单次事件显示。

载入演示后，原有已保存草稿保留在本机。点击 **撤销** 可以恢复载入前的工作区；点击 **保存草稿** 后，演示编排和波形可在刷新后恢复。B 组保留原内容。

本演示覆盖实际出声的双曲转场、滤波、低频、倒放和音量变化，以及事件编辑和草稿保存。菜单中的循环、Cue 和设备 FX 切换仍为编排命令数据，机器人动作为未验证的预排事件。
