# MIXDESK · DJ 工作台

根据本机 DJUCED 的功能结构，独立实现的本地四台 DJ 网页应用。打开后已载入两首原创合成演示曲，点击播放即可试听。

当前版本 0.8.4。最近补强音频核心：连续移调复用运行中的处理器，播放 / 跳点 / 暂停加入 4ms 淡化，Slip 抓碟支持后台时间线恢复与嵌套释放，并清理快速跳点后的旧处理器。验证与边界见 [音频核心记录](research/AUDIO-CORE.md)。完整 DJUCED 功能尚未重建；各项状态、证据与缺口见 [功能对照与验收](research/DJUCED-功能对照与验收.md)，Hercules 真机仍待验收。

这是以 MIXDESK 为主要使用入口、以 `app_dj_master/` 中的 DJ Master · ASTRIBOT / STUDIO 为预排基础的组合仓库。MIXDESK 负责正式播放、混音、采样、录音和控制器工作；DJ Master 负责两首曲目的时间轴预排与本地转场试听。构建产物、本机音频缓存和工具运行时不纳入版本控制。

完整的组合仓库使用方式、两个应用的启动命令和功能边界见 [使用说明](使用说明.md)。

## 打开

从 GitHub 新克隆后，先在项目目录执行 `npm ci` 和 `npm run build`，然后双击 **启动 DJ 工作台.command**。脚本使用 Python 3 提供本地静态页面并打开默认浏览器；启动时请保留终端窗口。推荐使用最新版 Chrome。

本地地址：<http://127.0.0.1:5173/>。

开发启动：

```sh
npm install
npm run dev -- --port 5173 --strictPort
```

## 使用

1. 点击“导入音乐”或拖入文件。支持浏览器可解码的 MP3、WAV、FLAC 等音频；每个文件上限 150 MB。
2. 选择双台或四台布局，点击曲目旁的 A / B / C / D 载入播放器。四台拥有独立音频、EQ、FX、循环及变速；切回双台不会停止 C / D，顶部状态按钮显示其播放状态并可重新展开。点击波形定位，点击播放开始试听。
3. 选择“同步 / 复制来源”，SYNC 会持续跟随所选来源台的有效 BPM（含变拍网格），再次点击解除；手动拉动变速会解除该台持续同步。速度范围可切换 ±6–100%，设为 100% 后拉到 −100% 会停止运输。点击 REV 可持续反向播放，Shift+R 也可切换；反向循环、Slip 后台时钟和 Hot Cue 预览会保持时间线方向。点击 BPM 数字手动校正原始速度。KEY LOCK 保持音高，可独立移调 ±12 半音；已运行音高处理时，连续调整移调不再重新填充处理器。首次启用、跳点及从旁路切入仍有缓冲时延及音质取舍，未与 DJUCED 原算法做 A/B 验证。
4. SET CUE 设置主 Cue；播放中按 CUE 返回并暂停，暂停时按住 CUE 预览，松开返回。预览期间按播放可保持播放，松开 CUE 不再停止。每台八个 Hot Cue，首次点击设置，再次点击跳转，Shift 点击清除；双击已设置的 Hot Cue 可编辑名称和颜色。
5. 通过三段 EQ、滤波器、单台音量与交叉推子混音。三段 EQ 各有 KILL 开关，双击 EQ、滤波器恢复默认值；点击 RESET 将交叉推子居中；各通道可分配到左侧、右侧或直通。混音器设置提供主输出余量、限幅器、Hamster、交叉推子曲线和自动增益范围；每台 FX 可切换到前推子或交叉推子后；FADER START 打开后，通道推子从静音位置抬起会启动该台。
6. “录音设置 / 缓存”可选压缩 WebM/M4A 或原生 16/24 位 PCM WAV；“录制混音”开始，再点结束并下载。WAV 录音可继续导出 192 kbps MP3；MP3 在本机编码，编码耗时和体积随录音长度变化。只录主输出，不录独立耳机预听和麦克风，最长 30 分钟。
7. 每台下方可编辑两组共享 FX Rack：每组有三个串联槽位，播放器可分配 Rack 1、Rack 2 或同时串联。选择效果、点击编号启用、调整干湿比；Echo、Delay、Tremolo 和 Gater 可选择拍长。混音器另有四个 Filter FX 预选槽，每台可选择槽位并独立调节普通 Filter 的强度；当前提供原版证据中的主要效果族的独立近似实现，参数、预设和路由仍未与原版逐项 A/B。
8. 采样器按 A/B/C/D 四台独立组织，每台四组，每组四个可选择样本：同组切换，不同组可同时播放。可按每台 4/8/16 格分页，也支持原版整数分页的 3 页布局；页内从每组取对应样本。提供六种模式（重触发、按住、开关 × 单次、循环）、每组音量和每台总音量、名称、入出点、增益、BPM、速度匹配及 Key Lock。量化切换保留旧声音到拍点；取消等待中的按住样本保留原音源。精确切换规则和 Key Lock 延迟仍待原版 A/B。单个样本限制 30 秒 / 30 MB。
   - .mxpack v4 导出四台全部 64 个样本及音频、空格和设置；兼容 v1–v3。旧版的每槽四个叠加层迁移成同组四个可选样本，不再一起触发；保留原 IndexedDB 记录与迁移备份，旧包原文件也保存在本机。迁移失败保留旧数据，刷新可重试。
   - “导入 DJUCED 采样包”可单选 .djz 直接解包，将四组样本导入当前采样台；也可同时选择 .djs 和音频。保留名称、六种类型、BPM、量化；缺失/无效 quant-enabled 使用 quant > 0，缺失/无效样本 type 按已核实的解析器取 0。包级 defaultSampleType 保存为当前台的“新载入模式”，只应用到之后单独载入的音频，不覆盖包内每格模式；可手动选择并持久保存。包内音频按完整相对路径匹配，不混用不同目录的同名文件；手动多选仍按文件名匹配且拒绝重复文件名。导入可取消；损坏包、缺音频、解码失败或事务失败保留旧数据和播放。
   - 量化间隔支持 1/4–32 拍，未播放来源台时立即触发。播放器的普通循环可提取到同台指定采样组的第一个样本。采样进入主输出与录音。封面与颜色等元数据、原版完整路由和时间拉伸算法仍未实现。
   - “导出 DJUCED 包”保存当前台为 .djz：采用原版可读取的 7-Zip + BZip2，关闭 LZMA 文件头和自动 Delta 过滤，内含 default.djs 与 16 位单/双声道 WAV。保留组/格索引、空位、六类型、BPM、quant/quant-enabled 和 defaultSampleType；入出点与样本增益写入 WAV，削波会显示计数。采样包 BPM 可编辑；优先使用导入包保存的速度，否则使用一致的样本 BPM 或来源台速度。导入包的速度随刷新和 .mxpack 保留，不直接更改当前播放速度。
   - 已用网页实际导出的六模式包验证本机 DJUCED 6.6.1 自动解包和载入，包标题、120 BPM、分组和空位显示正确，六段音频 PCM 完全一致。原版会给导入 WAV 添加标签，因此文件整体字节可变化；这不是音频损失。每段导出音频最多 30 MB，总量最多 256 MB，可取消压缩。组/台音量、速度匹配、Key Lock、分页与路由不写入 DJUCED 包，完整备份继续用 .mxpack。0.8.3 已补齐 .djz 直接导入、取消和失败回滚；输入包及解包文件总大小均限 256 MiB，目录最多 256 项。导入前校验路径、文件大小和音频；原版播放行为、音频 DSP 和时延 A/B 仍待验收，详见 [直接导入验证](research/DJZ-IMPORT.md)。
9. 每台播放器的 STEMS 面板提供人声、鼓组、低音和音乐四组增益、静音及独奏，并保存到本机混音会话。当前是明确标注的本地频段控制近似，默认设置保持干声旁路，调整后才进入滤波器组；它不等同于 DJUCED 的 AI 源分离模型。
10. 导入音频时会从起音中给出保守的首拍初值，并对较长音频按短窗口估计分段 BPM，生成可编辑的动态拍网格；同时计算每曲 Auto Gain，并给出自动 Hot Cue 初值。在“拍网格校正”中可继续定位首拍，再使用 QUANTIZE 吸附新 Cue，或重新生成八个自动 Hot Cue。“对齐拍点”按当前网格对齐来源台，“复制来源台”复制其播放状态。复杂变拍音乐仍需手动校正。
11. 原生 WAV 直接录主输出 PCM，支持 16/24 位、双声道及当前音频引擎采样率，本机分块保存；达到 30 分钟或 1 GiB 自动停止。录音列表可恢复已写入片段、重新导出 WAV 或 192 kbps MP3、删除缓存。压缩录音的 WAV 按钮仍是转码，不会恢复编码丢失的信息。

## 录音与恢复

“录音设置 / 缓存”位于播放器布局栏。选择 WAV 后，AudioWorklet 在音频线程采集主输出并打包为 PCM，录音分支不重复播放声音。文件格式、位深、声道顺序和样本数有自动化验证；缓存默认保留，手动点击“删除缓存”才移除。

意外刷新或关闭后，可以重新打开录音设置，导出已经提交到本机存储的部分。未提交片段可能丢失，浏览器清理/配额不足也会影响缓存；当前不是无限录制或操作系统级崩溃恢复。检测到存储故障、处理器异常或写入积压时停止并保留已提交内容。原生 WAV 最长 30 分钟或 1 GiB；压缩录音最长 30 分钟，仅保留当前会话中不超过 50 MB 的转码缓存。

导出 PCM 会把超过 −1～+1 的采样裁切到文件范围，录音列表显示超限计数。没有自动响度标准化和抖动处理，24 位不会提升原始音频或音频引擎的有效精度。独立耳机预听通过独立总线，未接入录音；硬件实际路由与长时间录制性能仍需真机测试。

## 音乐库与播放列表

- 普通列表支持新建、重命名、删除、批量加入/移出、防重复和顺序保存。按“列表顺序 / 升序”且没有隐藏曲目的筛选时，使用上下箭头调整顺序；删除列表或移出曲目不会删除音频。
- 智能列表按文本、风格、调性、BPM 范围、最低评分和收藏状态组合筛选；所有条件同时满足，曲目信息变化后自动更新。
- 搜索包含曲名、艺术家、专辑、风格、调性、注释和文件名。支持多条件筛选与字段排序。拖动曲目到普通列表可加入，到播放器可载入；触屏也可用 A / B / C / D 按钮。
- 导入时读取文件已有的曲名、艺术家、专辑、风格、年份、BPM、调性和封面；读取失败不阻止可解码音频导入。已有有效 BPM/调性标签优先，否则分别使用本地估算，并在曲库中用“≈”标记估算值。调性估算只用于浏览和筛选，不能替代 DJUCED 的专业 Key Detection。封面支持内嵌 JPEG / PNG / WebP，最多 5 MB。
- “信息”可编辑曲目属性、评分与注释，也可重新读取已缓存文件的标签。修改保存在曲库中并同步已载入的同一曲目；修改 BPM 会取消活动循环以使用新拍距。WAV / MP3 可导出带 ID3v2.3 标签和封面的新副本，原始音频文件保持不变；“重新关联文件”可为失联曲目选择新的本地音频并保留曲目身份、Cue、Hot Cue、循环等标记。
- “导出列表”下载当前筛选结果的 MIXDESK JSON 清单，不含音频。导入接受该 JSON 或 M3U / M3U8，匹配已经导入的曲目；缺失或不唯一匹配会跳过并提示。M3U 中的文件路径/网址不会自动读取或联网下载。智能列表 JSON 保存规则，导入后按当前曲库重新求值。
- “导出 Rekordbox XML”生成标准 `DJ_PLAYLISTS` XML，写入 `TRACK/@Location`、`TEMPO`、`POSITION_MARK`（Cue、Hot Cue、保存循环）和播放列表节点；导入列表也接受嵌套 Rekordbox XML，按曲名/艺术家或文件名匹配已导入的本地音频。导入还接受 Serato `.crate`，按其有界二进制记录读取 UTF‑16BE 曲目路径，再按文件名匹配已经导入的本地音频。浏览器只知道本地文件名，导出的绝对路径需要在 Rekordbox 中重定位；应用不会读取外部路径、复制或联网下载音频。
- 播放历史采用本应用的明确规则：每次载入曲目，累计检测到主输出信号至少 15 秒记一次。载入、Cue 按住预览、静音通道及仅耳机预听不计次；暂停再播/定位不会重复计次，重新载入后可再次计次。历史按曲目显示最近时间及次数，最多保留 10,000 条记录。此规则未经原版阈值对照，软件检测也不证明物理扬声器已经发声。
- 列表、收藏、元数据和历史持久保存在浏览器。多个同源标签页的这些编辑会事务合并并同步；各页独立导入/移除的音频仍需刷新其他页才更新。

## Pad 与循环演奏

每台 Pad 菜单包含五种模式，数字键 1–8 操作当前模式：

- HOT CUE：八个标记，点击设置/跳转，Shift 点击清除。
- LOOP ROLL：1/16、1/8、1/4、1/2、1、2、4、8 拍；播放时按住重复，松开恢复后台应有进度。鼠标、触摸、键盘均支持松开结束。
- SLICER：将当前 4 / 8 / 16 / 32 拍区域分为八片；按住重复指定切片，可选重复拍长，松开恢复进度。区域可以随播放移动，也可以固定在进入模式时的当前区域；换曲、定位或修改拍网格会重新计算固定区域。完整原版量化策略尚未实现。
- BEAT JUMP：−16 / −8 / −4 / −1 / +1 / +4 / +8 / +16 拍跳转。
- SAVED LOOP：空槽保存当前普通循环，点击已保存槽调用，Shift 点击清除。每曲八槽，保存成功后显示“已保存到本机”；同曲在多台载入时共享标记。

LOOP IN / OUT 手动标记边界，开启 QUANTIZE 时吸附到拍网格。开启 SLIP 后，普通循环和抓碟期间后台继续走时，退出循环或松开转盘后回到应有进度；支持反向播放和抓碟期间调速。关闭 SLIP 后松开转盘从抓碟位置续播，普通循环退出后从当前声音位置继续。Roll / Slicer 始终保留后台进度。波形虚线及 Pad 下方显示后台位置。

暂停、定位、换曲会取消正在按住的临时演奏；窗口失焦、页面隐藏、指针取消均释放临时 Pad，防止卡住。Roll / Slicer 要求播放器已播放。MIX 原始映射没有直接暴露这两组 Pad 消息，因此不把屏幕演奏模式套用到其原有 Hot Cue / Loop 消息上；MIX 的 Cue 按下与松开消息已接入。

## 独立耳机预听

混音器的“输出设置”中选择两个不同的实际音频输出设备，启用独立预听后，点击 PFL A / B / C / D 选择通道。可调耳机音量及 CUE / MASTER 混合。PFL 位于 EQ / FX 之后、通道音量与交叉推子之前，与主输出和录音隔离。

需浏览器同时支持 AudioContext / HTMLMediaElement 的输出选择，以及两个已授权设备。输出授权按钮仅在浏览器提供该 API 时显示；不请求麦克风。设备列表不足时，界面会说明原因。仅一个默认输出时无法实现独立预听。当前不支持单个多通道声卡内的 1/2、3/4 通道分配。

设备变化时预听立即静音并关闭，需重新选择输出；切换失败会尝试恢复原主输出。自动化测试覆盖音频分离、录音无预听串入、模拟输出授权失败和热拔出。**尚未验证真实双设备路由及端到端时延。**

## Hercules DJControl MIX

右上角“控制器” → “查找 MIDI 设备” → 允许浏览器访问 MIDI → 选择输入、输出 → “连接选定端口”。只列出名称匹配的 DJControl MIX，排除 MIX ULTRA。不启用 SysEx，不写入固件。

电脑须先识别到实际在线 MIDI 端口；USB 供电不等于已建立 MIDI 通信。支持通过系统端口接入，不预设 USB 或蓝牙已可用。内置浏览器不支持时，请使用 Chrome。

已实现软件映射：播放、Cue/Shift+Cue 停止、Sync、Hot Cue/清除、循环、FX 开关、Sampler、音量、滤波、低频、变速和交叉推子，PFL 和耳机音量，以及对应状态灯消息。普通 Jog 做临时弯音，Shift+Jog 做四拍跳转；Shift+触摸 Jog 按当前曲库视图上下选择歌曲，Load A/B 将选中歌曲载入对应台。Scratch 模式可切换，Scratch Jog 使用双向短音粒近似。播放与混音映射 A / B 台；四个采样垫触发 C / D 采样台各组当前选中的样本，Shift 停止对应组，反馈读取组播放状态。连续旋钮按 DJUCED 映射的 MSB/LSB 配对解码为 14 位，变速旋钮带软件 Pickup 后再应用到音频节点。尚未与原版做音频 A/B，也没有接入真机或验证延迟。

快捷键：A / C / D 选台，B 或 Shift+B 拍 BPM，Shift+S 切换 Scratch，Shift+左右将曲库选中项载入 A / B，左右按一拍跳转，上下移动曲库选中项，1–8 操作当前 Pad 模式，L 切换循环，⌘K 搜索。空格仍用于播放/暂停；原版 `keyboard.xml` 的浏览器展开动作在本地页面中保留为界面操作。

导入文件、手动 BPM、Cue 点和首拍位置保存在当前浏览器的 IndexedDB。清理站点数据会删除这些缓存；更换浏览器、端口或主机名会使用另一份缓存。保存循环槽、布局、用户采样槽位、采样器全局设置以及混音器/FX 工作状态也会保存；当前播放进度、临时循环和独立输出设备选择不跨刷新保存；原生 WAV 录音分块会保存在独立缓存。

## 范围

当前是可播放和录音的体验版，不是 DJUCED 原始源码。BPM、首拍和动态网格是本地启发式估算；SYNC 匹配速度，拍点对齐使用当前网格。VJ 提供本地双通道视频、跟随 A/B Deck、透明度、定位、浏览器全屏、可拖到第二块显示器的独立双路输出窗，以及本地浏览器滤镜特效、CSS 动画和 LRC/SRT 歌词层；尚未实现 OpenCV 帧处理、窗口协议级几何控制、原版特效 DSP、动画/素材下载服务和 PRO 权限策略。其他尚未实现项包括真实 Stems 分离、完整 Slip 交互、文件标签写回/Relocate、专业多通道声卡路由、流媒体服务、Ableton Link 和 Assistant/SmartMix。Rekordbox XML、Serato Crate 已有基础曲库交换；固定区域 Slicer、四台和预听已有独立实现，音质、时延和全部交互仍需原版对照。请以功能对照表为准，不将当前版本称作全功能复制。

本轮分析材料见 [research/DJUCED-分析记录.md](research/DJUCED-分析记录.md)。应用原件保持未修改。
